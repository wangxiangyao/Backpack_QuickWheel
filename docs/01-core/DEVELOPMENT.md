# 开发指南

## 构建与开发命令

### 构建 Mod
```bash
# 构建项目（输出到游戏的 Mods 目录）
dotnet build Great_backpack.csproj
```

输出路径已在 `.csproj` 文件中自动配置为：`D:\steam\steamapps\common\Escape from Duckov\Duckov_Data\Mods\Great_backpack\`

### 开发配置
- 目标框架：.NET Standard 2.1
- 游戏路径：通过 `.csproj` 中的 `DuckovPath` 变量配置
- 依赖项标记为 `<Private>false</Private>` 以防止复制到输出目录


### 调试
- 使用 `#if DEBUG` 块实现仅开发环境的功能
- 在 Debug 构建中自动导出标签
- `TagExporter.CheckSpecificTags()` 验证所需标签是否存在

### 添加新配件
1. 在 `BackpackModConfig.cs` 的 `AttachmentItemConfigs` 中添加条目
2. 使用 `UnifiedSlotTypes` 中的插槽以保持一致性
3. 为 zh-CN 和 en-US 提供本地化文本
4. 在 `.csproj` 中将自定义图标作为资源嵌入
5. 使用 349100-349999 范围内的唯一 TypeID


### 标签限制
- 插槽限制标签必须与游戏的系统标签完全匹配（区分大小写）
- 常用标签："key"、"SpecialKey"、"Injector"、"Healing"、"Drink"、"Food"、"Explosive"、"Magazine"、"MeleeWeapon"
- 多个标签创建 OR 逻辑（物品匹配任意标签即可）

### 已知限制
- 背包 TypeID 硬编码（36-40）
- 配件 TypeID 必须手动分配且唯一
- 每次初始化都会导出标签（性能影响）
- 需要 2 秒延迟等待游戏物品系统初始化

## 📝 **【核心原则】三层持久化开发方法论**

### 🎯 **原则声明**
**"每完成一个重要任务，必须完成三层持久化记录，一个都不能少！"**

### 📋 **三层持久化体系**

#### 第一层：Git提交记录 📦
**目的**: 代码变更历史和可追溯性
**时机**: 功能完成，代码稳定后立即执行
**要求**:
- [x] **详细提交信息**: 清晰描述问题和解决方案
- [x] **技术细节记录**: 记录关键代码变更和设计决策
- [x] **影响范围说明**: 明确修改的文件和功能模块

**提交信息模板**:
```
<type>: <功能简述>

🎯 核心问题：
- 问题1：具体描述
- 问题2：具体描述
- 问题3：具体描述

🔧 解决方案：
- 解决方案1详细描述
- 解决方案2详细描述
- 关键代码变更记录

📊 影响范围：
- 性能改善指标
- 用户体验提升
- 系统稳定性增强
```

#### 第二层：项目文档更新 📊
**目的**: 项目级状态跟踪和团队协作
**时机**: 功能验证完成后，与其他功能集成前
**要求**:
- [x] **TODO清单更新**: 标记任务完成状态，记录关键信息
- [x] **CHANGELOG记录**: 详细的问题分析和解决方案记录
- [x] **README更新**: 版本信息和主要改进说明
- [x] **版本管理**: 确保版本号正确反映功能状态

**TODO清单模板**:
```markdown
- [x] 功能名称（完成状态）
  - 位置：文件路径:行号
  - 完成：具体实现细节
  - 解决：技术问题或用户需求
```

#### 第三层：技术设计文档 📖
**目的**: 完整的技术实现细节和知识传承
**时机**: 重要功能或复杂问题解决后，项目稳定时
**要求**:
- [x] **完整的问题分析**: 根本原因分析和技术挑战
- [x] **详细的实现方案**: 技术架构和代码逻辑
- [x] **代码变更记录**: 每个文件的具体修改和示例代码
- [x] **性能影响分析**: 量化的改善指标和用户体验数据
- [x] **调试方法论**: 经验教训和最佳实践总结
- [x] **测试验证记录**: 功能测试、性能测试、边界情况测试
- [x] **验收标准**: 功能、性能、质量三个维度的验收清单

**技术文档结构**:
```markdown
# [功能名称]技术设计文档

## 概述
- 功能描述、开发日期、状态、优先级、提交记录

## 问题分析
- 问题描述、根本原因、影响范围

## 解决方案
- 技术架构、设计原则、实现方案

## 代码实现
- 文件变更、关键方法、核心代码示例

## 性能分析
- 性能指标、优化效果、资源使用

## 经验总结
- 关键学习、最佳实践、技术债务清理

## 测试验证
- 功能测试、性能测试、验收标准
```

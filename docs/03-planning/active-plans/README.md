# 当前进行中的任务规划

这里存放正在执行中的复杂任务的完整规划信息。

## 📋 当前活跃任务

*目前没有活跃的复杂任务规划*

## 📁 文档结构

每个复杂任务都有独立的文件夹，包含：
- `analysis.md` - 问题理解分析
- `design.md` - 解决方案设计
- `tasks.md` - 具体任务分解（可选，主要内容在TODO.md中）

## 🔗 使用方法

### 开始新任务
1. 在此目录下创建任务文件夹：`[task-name]/`
2. 按照任务规划最佳实践创建分析和设计文档
3. 更新此README添加新任务

### 查看任务进展
1. 查看任务文件夹中的规划文档
2. 查看 `../../01-core/TODO.md` 了解具体执行进度
3. 查看对应的实现文档（`../../04-technical/`）

### 任务完成后
1. 将规划文档移动到对应的分析和设计归档目录
2. 更新此README移除已完成任务
3. 确保所有文档都有完整的三层持久化记录

## 📝 归档位置

完成的任务规划将移动到：
- 分析文档：`../analyses/[task-name]-analysis.md`
- 设计文档：`../designs/[task-name]-design.md`

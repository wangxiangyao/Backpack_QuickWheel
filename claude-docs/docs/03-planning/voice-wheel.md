# 语音轮盘功能开发计划

## 🎯 功能概述

为《逃离鸭科夫》Mod添加语音轮盘系统，允许玩家通过快捷键T触发语音轮盘，选择不同的语音进行播放，同时显示气泡文字并影响周围NPC。

## 📋 需求详情

### 核心功能
- **语音播放**：支持音频文件播放 + 气泡文字显示
- **轮盘选择**：T键长按显示8格轮盘，鼠标方向选择
- **快捷触发**：T键短按直接播放当前选中语音
- **默认语音**：提供"嘎"语音作为默认选项

### 高级功能
- **自定义语音**：用户可添加自定义语音文件
- **影响范围**：可调节语音对NPC的影响范围（10-50米）
- **轮盘布局**：用户可自定义语音在轮盘中的位置
- **特殊符号**：支持emoji和特殊符号显示

## 🏗️ 技术架构

### 核心组件
```
VoiceWheelSystem/
├── VoiceWheelManager.cs       # 主控制器
├── VoiceWheelSelector.cs      # 轮盘UI选择器
├── VoiceItem.cs              # 语音数据结构
├── VoiceWheelData.cs         # 配置数据管理
├── VoiceBubbleManager.cs     # 气泡显示管理
├── VoiceNPCManager.cs        # NPC交互管理
└── VoiceConfigManager.cs     # 配置界面管理
```

### 复用架构
- 轮盘UI系统复用现有的`ItemWheelSelector`九宫格布局
- 输入拦截机制复用`InputInterceptor`长按检测
- 数据持久化参考现有轮盘布局保存机制

## ⚠️ 风险识别

### 技术风险
- **音频文件兼容性**：不同格式的音频文件支持
- **性能影响**：轮盘显示对游戏性能的影响
- **Unity版本兼容**：UI组件在不同Unity版本的兼容性

### 实施风险
- **开发时间**：UI界面开发可能超出预期时间
- **测试复杂度**：NPC交互逻辑需要大量测试验证
- **用户体验**：轮盘操作的流畅性和响应速度

### 应对策略
- 先实现核心功能，确保基本可用
- 分阶段测试，每个阶段都有可演示的成果
- 保留回退方案，确保不影响现有功能

### 第四阶段：三层事件订阅架构完善
**时间**: 2025年11月3日
**核心问题**: 配件移除时物品无法正确从轮盘移除

#### 三层架构定义
```
第一层：背包自身 → 监控背包槽位内容变化
├── 处理：OnBackpackChanged → OnBackpackSlotContentChanged

第二层：配件物品 → 监控配件拔出事件 + 配件内部槽位变化
├── 插入：OnAttachmentInternalSlotChanged (internalItem != null)
├── 拔出：OnAttachmentUnplugged (配件拔出事件)

第三层：配件内物品 → 监控物品拔出事件
├── 拔出：OnItemUnpluggedFromSlot (物品拔出事件)
```

## 🔧 核心技术突破

### 1. 精确物品引用获取
**问题**: 通过slot内容变化无法精确获取被移除的物品引用
**解决**: 订阅物品拔出事件，直接获取物品引用

```csharp
// 第三层：订阅配件内物品的拔出事件
item.onUnpluggedFromSlot += OnItemUnpluggedFromSlot;
```

### 2. 批量物品移除机制
**问题**: 配件移除时无法批量处理内部物品
**解决**: 新增BatchRemoveItems方法

```csharp
public void BatchRemoveItems(ItemCategory category, List<Item> itemsToRemove)
{
    // 批量移除所有指定物品
    // 处理选中状态重新选择
    // 自动UI更新
}
```

### 3. 增量更新替代全量刷新
**问题**: 物品放入时触发全类别检测，性能浪费
**解决**: 实现精确的增量更新

```csharp
// 修复前：全量更新

// 修复后：增量更新

{

}
```

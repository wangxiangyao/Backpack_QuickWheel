# 行军包Mod - Great Backpack Mod

为《逃离鸭科夫》游戏开发的背包配件系统Mod。

## 功能特性

- ✅ 为现有背包添加配件插槽
- ✅ 创建多种配件物品（侧面包、战术包、子弹袋等）
- ✅ 嵌套配件系统（配件包中还有配件包）
- ✅ 完整的Tag管理系统
- ✅ 智能配件效果计算

## 安装说明

1. 将编译后的 `Great_backpack.dll` 放入游戏目录的 `Duckov_Data/Mods/Great_backpack/`
2. 确保同时包含 `info.ini` 和 `preview.png`

## 开发环境

- Unity Mod 开发模板
- .NET Standard 2.1
- Visual Studio 2022
